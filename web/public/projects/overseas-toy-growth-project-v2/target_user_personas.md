# 目标用户画像

## 1. 新手收藏者 Mia

- 年龄：18-24
- 市场：美国大学生/年轻职场人
- 动机：被 TikTok 开箱、OOTD 和收藏展示种草，想买第一只正品。
- 顾虑：分不清真假，不知道官方价格和合理溢价，害怕被坑。
- 触发内容：真假鉴定 15 秒、beginner price guide、safe buying checklist。
- 关键指标：save rate、profile CTR、首次 wishlist add。

## 2. 交易型藏家 Jay

- 年龄：25-34
- 市场：美国/加拿大收藏社群
- 动机：买卖、交换限定款，关注补货和价格波动。
- 顾虑：卖家可信度、付款后不发货、运输丢件、纠纷处理。
- 触发内容：seller trust badge、protected payment walkthrough、price band。
- 关键指标：verified listing rate、checkout start、protected transaction。

## 3. 礼物/生活方式买家 Ava

- 年龄：23-35
- 市场：美国生活方式消费人群
- 动机：买可爱配饰、礼物或跟随流行趋势。
- 顾虑：不了解系列、价格和真假特征，对二手交易规则陌生。
- 触发内容：official-vs-resale price card、gift guide、safe seller checklist。
- 关键指标：product dwell time、price-card clicks、checkout start。

## 用户画像背后的判断

这三个画像对应三种增长入口：Mia 来自内容种草，Jay 来自高意图交易社区，Ava 来自生活方式消费。它们共同的转化阻碍不是「对潮玩没兴趣」，而是「不知道怎么安全地买」。
