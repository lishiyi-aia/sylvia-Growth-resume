01 · Project Brief

从“被种草”到“敢交易”

研究对象是一款面向海外收藏者的潮玩二手交易 App。项目不假设已经上线或取得商业结果，而是展示如何将公开证据转化为可执行的增长运营方案。

核心研究命题

当用户已经对 Labubu、Designer Toys 等潮玩产生兴趣，哪些因素仍会阻碍他们在新的 C2C App 中完成购买？

研究结论：用户不缺兴趣，主要决策成本来自真假鉴定、卖家可信度、价格透明和交易保护。增长策略因此从“扩大曝光”转向“先建立可信交易理由，再放大内容与社群”。

市场研究财报、监管信息与品类信号
用户洞察用户分层、路径与问题编码
增长运营渠道、内容与达人策略

02 · Evidence System

公开数据如何进入运营判断

项目建立 Evidence Matrix，逐条记录来源、日期、指标、原始链接、使用场景与可信度。硬数据和方向性观察分开使用，避免把社区讨论误写成市场规模。

INPUT 01

证据采集

财报、监管警告、平台政策、公开社区与创作者账号。

PROCESS 02

结构化编码

按市场、风险、交易、社区、内容与达人六个维度打标签。

MODEL 03

模型计算

问题优先级、竞品矩阵、KOL/KOC 加权评分与 RICE 排序。

OUTPUT 04

运营决策

确定产品信任机制、渠道角色、内容主题和测量指标。

A · 事实依据

公司财报、政府监管与平台官方政策。用于市场数字、风险事实和规则对比。

B · 方向判断

行业报告、公开平台页面与社区分析。用于趋势判断和内容主题设计。

C · 候选观察

创作者公开主页与单条内容表现。用于建立候选池，正式合作前需刷新。

04 · User Insight

三类用户，共用一条信任路径

用户分层依据内容入口、交易经验和购买目的建立。三类用户偏好不同，但都会在 Compare、Evaluate 与 Purchase 阶段寻找可信信息。

PERSONA 01

内容种草型新用户

通过 TikTok、Reels 与开箱内容进入品类，关注热门款和隐藏款，但缺少真假、价格和二手交易经验。

关键任务：降低第一次交易的学习成本
PERSONA 02

交易型收藏者

持续购买、出售或交换藏品，关注卖家信誉、商品状态、近期成交价格、物流效率与纠纷处理。

关键任务：提高信息密度与交易确定性
PERSONA 03

礼物与生活方式用户

购买频率较低，容易受到视觉内容和送礼场景影响，更重视流程简单、商品可信和交付确定性。

关键任务：用清晰证明缩短决策路径

07 · Trust Engine

五层信任机制

用户问题不只转化为内容选题，也进入产品信息结构。五层机制分别回答“商品、卖家、价格、交易和记录是否可信”。

LAYER 01

商品可信

QR、全息标识、UV 标记和包装细节上传清单。

LAYER 02

卖家可信

身份、历史成交、发货速度、取消与纠纷记录。

LAYER 03

价格可信

官方原价、近期成交区间与不同状态价格差异。

LAYER 04

交易可信

受保护支付、追踪、收货确认与争议处理。

LAYER 05

记录沉淀

认证记录、收藏档案、信用积累与分享。

10 · Measurement Design

指标不是结果，而是运营判断工具

作为个人研究项目，这里不展示虚构的投放或交易结果。指标树用于说明：若产品上线，应如何定位问题发生在获客、信任建立、交易还是质量环节。

North Star

受保护交易数

同时反映需求、信任与履约完成。

Acquisition

有效访问

内容点击率、渠道访问与达人链接访问。

Activation

首次有效行为

收藏、愿望单、搜索与认证信息查看。

Trust

认证资料完成

衡量信任功能是否真正被采用。

Conversion

结账到支付

识别价格、运费和支付流程阻力。

Quality

纠纷与假货申诉

增长不能以牺牲交易质量为代价。

Retention

D7与愿望单回访

观察收藏习惯和持续需求。

Creator

每激活用户成本

评价达人不能只看播放量。

点击高，激活低

检查落地页是否解释认证、卖家信用和交易保护，而不是继续增加曝光。

激活高，结账低

检查价格、运费、支付和争议说明，定位 Purchase 阶段阻力。

交易上升，纠纷同步上升

停止放大，优先加强商品审核和卖家风险控制。

收藏高，访问低

内容有信息价值，但 CTA 或入口表达需要调整。
