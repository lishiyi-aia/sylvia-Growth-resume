# 海外潮玩二手交易 App 增长项目：Trust-led Growth Case Study

## 1. 项目定位

这是一个可以放进简历和作品集的个人研究项目，目标不是假装自己已经在公司上线过活动，而是证明你具备这个岗位最看重的能力：海外用户理解、社媒/社区增长、KOL 合作、竞品分析、数据驱动运营和跨团队产品化思考。

项目问题：

> 如果海外用户已经被 Labubu / designer toys 种草，为什么仍然不一定愿意在一个新的二手交易 App 里完成下单？

我一开始的假设是「增长问题 = 流量问题」，所以会优先做 TikTok 曝光、KOL 开箱、活动裂变。但公开数据和平台规则对比后，我把核心判断改成：

> 对潮玩二手交易来说，用户不缺兴趣，真正的转化阻碍是信任。增长策略必须先把 trust proof 前置，再放大内容和裂变。

## 2. 数据与来源方法

我把数据分为三类，避免把公开事实和个人假设混在一起：

1. 公开事实数据：POP MART 财报、Whatnot/Mercari 官方规则、Reddit 社区规模、CPSC/BBB 风险信息、TikTok Shop 页面信号。
2. Desk research 编码：把每个来源按痛点主题打标签，例如假货、支付、卖家可信度、价格透明、补货焦虑、社群身份。
3. 运营建模假设：AARRR 漏斗、KOL/KOC 评分、内容实验优先级。它们不是已发生业绩，而是上线前的测量方案。

## 3. 关键发现

### 发现一：海外潮玩需求是真实增长，而不是主观感觉

POP MART 披露 H1 2026 收入 RMB 17.17bn，同比增长 23.8%；The MONSTERS 收入 RMB 4.45bn；美洲收入 RMB 1.89bn。Whatnot 报告的直播购物市场规模为 $22bn，2025 年平台卖家直播销售额 $8bn。TikTok Shop 的 POPMART US SHOP 页面也显示了较强的官方内容电商信号。

我的判断：潮玩不是一个只靠小圈层热度的品类，它已经具备海外内容种草、社群讨论和交易转化的基础。

### 发现二：转化瓶颈不是「看不见商品」，而是「不敢相信交易」

CPSC 对 fake Labubu 发出安全警告，BBB Scam Tracker 能看到大量 Labubu 相关骗局报告；Whatnot 和 Mercari 的官方规则都把 buyer protection、authenticity、shipping protection 放在核心位置。

我的判断：新 App 如果只做开箱内容或达人带货，会吸引流量，但很难解释用户为什么要在这里交易。更有效的定位是「潮玩交易的信任基础设施」。

### 发现三：Reddit/TikTok 分工不同

Reddit 的 r/labubu 和 r/LabubuDrops 显示用户有展示收藏、讨论真假、买卖交易、补货追踪等高意图行为；TikTok 更适合让用户被种草、看见玩法、接受 KOC 的真实体验。

我的判断：TikTok 负责 acquisition 和 creative testing；Reddit/Discord 负责 user insight、trust education 和 community credibility。不能把 Reddit 当广告位硬推。

### 发现四：早期 KOL 合作不应按粉丝数排序

Sprout Social 和 CreatorIQ 的趋势报告都指向一个共同判断：创作者合作越来越需要证明 ROI，内容相关性、受众匹配、信任感比粉丝数更重要。

我的判断：早期应该先做 20 个 micro-KOC/KOL 候选池，用小预算验证「真假鉴定」「安全交易」「价格解释」「收藏展示」四类内容的转化质量，再放大表现最好的素材。

## 4. 使用的模型

### Trust Barrier Model

我把用户路径拆成 Discover -> Compare -> Evaluate -> Purchase -> Retain，并把每个阶段的信任阻碍打分。热力图显示最高风险集中在 Evaluate 和 Purchase，因此增长动作必须把认证、卖家可信度、交易保护提前展示。

### AARRR Funnel

我建立了一个假设漏斗：100,000 impressions -> 1,500 clicks -> 180 signups -> 81 activated users -> 18 trade-intent users -> 6 protected transactions。这个不是业绩包装，而是为了明确上线后该看哪些指标。

### KOL/KOC Scoring Model

权重：品类相关性 30%，社区信号 20%，市场匹配 20%，信任教育适配 20%，品牌安全 10%。原因是二手交易 App 的核心不是「谁声量最大」，而是「谁能降低用户的不信任」。

## 5. 策略产出

1. 产品策略：发布前认证 checklist、卖家信用页、成交区间、受保护支付说明、争议入口。
2. TikTok 内容：真假鉴定 15 秒、开箱/展示、价格解释、补货提醒、安全交易流程。
3. Reddit/Discord 社区：每周真假鉴定帖、价格讨论帖、买卖安全指南、collector AMA。
4. KOL/KOC 合作：先做 20 人候选池；每人给不同内容 brief；用 tracking link/code 追踪 CTR、signup、activation 和 protected transaction。
5. 裂变活动：Verified Collector Pass，邀请好友完成认证/愿望单后解锁 fee coupon 或 badge；用 dispute rate 做护栏，避免低质量拉新。

## 6. 我会在面试中如何解释这个项目

我不会说「我做了一个表格」，而会说：

> 我做这个项目时，最开始以为海外潮玩二手交易的增长关键是 TikTok 曝光和 KOL 开箱。但我看了 POP MART 的海外增长、Whatnot/Mercari 的交易保护机制、Reddit 社区讨论和 CPSC/BBB 的假货风险后，发现用户的兴趣已经存在，真正影响转化的是信任。所以我把方案从流量驱动改成 trust-led growth：先用真假鉴定、卖家可信度、受保护支付和价格透明降低交易顾虑，再用 TikTok/KOC 去放大内容。最后产出了一套竞品定位、用户路径、信任阻碍热力图、AARRR 指标、KOL 评分模型和裂变活动方案。
