# 简历与面试版本

## 简历项目名称

海外潮玩二手交易 App 增长策略研究 | 个人项目

## 简历写法：稳妥版

- 基于 POP MART 财报、Whatnot/Mercari 官方规则、Reddit 社区数据、CPSC/BBB 风险信息及 TikTok Shop 页面信号，独立完成海外潮玩二手交易 App 增长研究，搭建竞品定位、用户路径、信任阻碍热力图与 AARRR 漏斗模型。
- 将用户转化问题从「流量不足」重构为「交易信任不足」，提出真假鉴定、卖家信用、价格透明、受保护支付和社区内容种草结合的 trust-led growth 策略。
- 设计 20 个 KOL/KOC 候选池及评分模型，按品类相关性、社区信号、市场匹配、信任教育适配和品牌安全打分，并规划 TikTok/Reddit 内容测试、tracking link/code 归因和核心指标体系。

## 简历写法：更强一点

- 独立搭建海外潮玩二手交易 App 增长 case study，整合 19 个公开来源与 3 类竞品（直播交易、横向 C2C、官方内容电商），输出用户画像、竞品 2x2、信任阻碍热力图、KOL/KOC 评分模型及 AARRR 测量方案。
- 通过公开投诉、平台保护政策和社区交易话题编码，识别「真假鉴定、支付安全、卖家可信度、价格透明」为影响转化的核心阻碍，并据此设计产品功能与社媒内容联动策略。
- 规划 TikTok/Reddit 增长实验：以真假鉴定、安全交易、价格解释、开箱展示为内容支柱，设置 CTR、注册率、认证完成率、交易意向率、受保护成交数和纠纷率等指标，形成可复盘的增长闭环。

## 面试 60 秒讲法

我做的是一个海外潮玩二手交易 App 的增长策略项目。最开始我以为这个品类的增长重点是 TikTok 流量和达人开箱，但调研后发现，用户对 Labubu 和潮玩本身已经有很强兴趣，真正卡住交易的是信任问题，比如真假鉴定、卖家是否可靠、付款后是否能收到货、价格是不是被炒高。

所以我把项目主线改成 trust-led growth。数据上，我用了 POP MART 财报判断市场热度，用 Whatnot/Mercari 的官方规则拆交易保护机制，用 Reddit 社区数据观察用户讨论重点，再用 CPSC 和 BBB 的公开风险信息验证假货和诈骗确实是用户顾虑。基于这些，我做了用户路径、信任阻碍热力图、竞品定位、AARRR 漏斗和 KOL/KOC 评分模型。

最后的策略不是简单找达人发帖，而是先设计能降低顾虑的内容和产品机制，比如真假鉴定 checklist、卖家信用展示、价格区间、受保护支付说明，再让 KOC 用真实收藏和安全交易内容去放大。这样增长不是只看播放量，而是看注册、激活、认证完成、交易意向、受保护成交和纠纷率。

## 面试官追问：你怎么做 KOL 合作？

我会先把 KOL 合作拆成 5 步：

1. 选人：不只看粉丝数，而是用评分模型看品类相关性、社区信号、市场匹配、信任教育能力和品牌安全。
2. 分层：先找 micro-KOC 测试内容，因为二手交易更需要真实感；表现好再放大到中腰部达人。
3. Brief：每个达人只测一个主题，比如真假鉴定、安全交易、价格解释或开箱展示，避免一次塞太多信息。
4. 归因：每个达人使用独立 tracking link、邀请码或优惠码，追踪 CTR、注册率、激活率和交易意向。
5. 复盘：不是看播放量最高的达人，而是看每个 activated user 和 protected transaction 的成本，以及评论里是否出现信任相关问题。

## 面试官追问：为什么说是数据驱动？

我没有把数据驱动理解成做一张漂亮表格，而是先用数据改变判断。我的初始判断是做流量，但公开来源显示假货、诈骗、平台保护机制和社区交易问题都很突出，所以我把策略改成先解决信任。之后每个动作都对应指标：TikTok 看 CTR 和完播，Reddit 看高意图评论和 AMA 参与，产品侧看认证完成率、checkout start，交易侧看受保护成交和纠纷率。

## 注意

简历里不要写「实际提升了多少 GMV/转化率」，除非你真的跑过活动。可以写「搭建模型」「设计实验」「完成公开数据研究」「输出增长方案」。这样既贴岗位，也不会被面试官追问到露怯。
