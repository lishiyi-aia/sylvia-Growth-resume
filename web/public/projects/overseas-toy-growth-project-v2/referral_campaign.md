# 裂变活动方案：Verified Collector Pass

## 活动目标

把「被种草的新用户」转化为「敢交易的可信用户」，同时避免只追求低质量注册。

North-star metric：Protected transaction completed，受保护成交数。

## 用户路径

1. 老用户完成基础认证，获得 Collector Pass。
2. 老用户邀请新用户加入 waitlist 或下载 App。
3. 新用户需要完成至少一个高质量动作：完成真假鉴定 checklist、添加 wishlist、关注一个 seller、或完成首次商品搜索。
4. 双方解锁奖励：交易保护券、手续费减免券、限定 badge、优先补货提醒。
5. 如果邀请用户产生异常纠纷、疑似虚假交易或高退款，新老用户奖励延迟发放。

## 为什么这样设计

普通裂变容易带来无效注册，但 C2C 二手交易更怕低质量用户和欺诈风险。所以活动不能只奖励 invite 或 signup，要奖励 activation 和 trust behavior。

## 活动机制

- 入口：TikTok link-in-bio、Discord 身份组、Reddit 实用帖、App 内 seller profile。
- 奖励：首单 buyer protection coupon、seller fee coupon、Verified Collector badge、drop alert priority。
- 限制：每个用户前 5 个邀请奖励更高，之后降低；同设备/同支付方式异常不计入。
- 内容配合：KOC 发布「如何安全买第一只 Labubu」或「我如何确认卖家可信」。

## 指标

- Invite click rate
- Invited signup rate
- Invited activation rate
- Wishlist add rate
- Authentication checklist completion rate
- First checkout start
- Protected transaction completed
- Dispute rate
- Counterfeit claim rate
- Reward abuse rate

## 复盘方式

不要只问活动带来多少注册，而要按 cohort 看：

- KOC 邀请用户 vs 普通 TikTok 点击用户，谁的 activation 更高？
- 完成真假鉴定 checklist 的用户，checkout start 是否更高？
- 使用 buyer protection coupon 的用户，纠纷率是否可控？
- 评论里用户还在问哪些信任问题？
