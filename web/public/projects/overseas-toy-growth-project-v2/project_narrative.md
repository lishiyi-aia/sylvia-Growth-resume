# 海外潮玩二手交易 App 增长策略研究

## 项目定位

个人独立增长研究项目。研究对象是一款面向海外收藏者的潮玩二手交易 App，核心问题是：当用户已经对 Labubu、Designer Toys 等潮玩产生兴趣，哪些因素仍会阻碍他们在新的 C2C App 中完成购买？

项目不假设已经上线，也不使用虚构的投放或交易结果。研究重点是展示如何从公开证据出发，完成用户洞察、竞品分析、增长策略、内容运营、达人筛选和指标设计。

## 数据体系

项目建立19项 Evidence Matrix，每条记录包含来源、日期、指标、原始链接、研究用途与可信度等级。

- A级：公司财报、政府监管与平台官方政策，用于硬数据和规则事实。
- B级：行业报告、公开平台页面与社区分析，用于方向判断。
- C级：创作者公开主页与单条内容表现，用于候选筛选，正式合作前需要刷新。

POP MART 2024年收入为人民币130.38亿元，同比增长106.9%；其中 THE MONSTERS 收入为人民币30.41亿元，同比增长726.6%。数据来自 POP MART 官方年度业绩公告。

CPSC 对仿冒 Labubu 的安全警告、Whatnot 的假货与购买保障政策、Mercari 的第三方图片鉴定及运输保障，共同说明真假、履约与交易保护是该品类的重要决策条件。

## 用户与问题模型

目标用户分为内容种草型新用户、交易型收藏者、礼物及生活方式用户。

用户路径拆分为 Discover、Compare、Evaluate、Purchase、Retain。公开证据按照真假风险、支付保护、卖家信用、价格透明、补货焦虑和社区身份六类问题编码，并使用“来源出现频次 × 决策影响程度”排序。

最高优先级为真假与仿冒风险40分、支付与交易保护35分、卖家可信度24分和价格透明度20分。由此确定 Evaluate 与 Purchase 是策略重点。

## 竞品判断

- Whatnot：直播与互动交易强，同时具备假货管理和购买保障。
- Mercari：C2C交易流程成熟，具备图片鉴定、支付和运输保障。
- TikTok Shop：内容发现与官方供给强，用户间二手流转能力有限。
- Reddit / Discord：收藏讨论真实、兴趣密度高，缺少标准化交易保障。

策略方向是连接收藏身份、商品证明、价格信息与受保护交易。

## Trust Engine

1. 商品可信：QR、全息标识、UV标记和包装细节上传清单。
2. 卖家可信：身份、历史成交、发货速度、取消与纠纷记录。
3. 价格可信：官方原价、近期成交区间和不同商品状态价格差异。
4. 交易可信：受保护支付、物流追踪、退款与争议处理。
5. 记录沉淀：认证记录、收藏档案和信用积累。

## 内容与达人运营

内容主题对应用户路径：发现阶段做开箱和补货；比较阶段做价格区间；评估阶段做真假识别；交易阶段做支付和物流说明；留存阶段做收藏墙、愿望单和UGC。

达人候选池包含20位公开账号，评分权重为品类相关性30%、社区互动20%、市场匹配20%、信任教育能力20%、品牌安全10%。评分只用于研究分层，正式触达前需要刷新粉丝地域、近30天表现、报价和品牌安全。

## 指标与优先级

指标树以受保护交易数为北极星，向下连接获客、激活、认证、结账、交易质量、留存和达人效率。RICE模型用于比较真假辨别内容、发布前认证清单、购买保障说明、Reddit讨论和卖家信用标识等策略。

## 研究闭环

公开证据 → 用户问题 → 模型判断 → 运营策略 → 指标设计 → 复盘规则。

研究结论：海外潮玩二手交易的增长重点，是用可验证的信息降低用户从“喜欢”到“敢买”的决策阻力。
